# CCLP Mobile

CCLP v2.5 Excel engine을 모바일 우선 Next.js 웹앱으로 이식한 MVP입니다.

## 실행
```bash
npm install
npm run dev
```

## Vercel 배포
1. 이 폴더를 GitHub 저장소에 업로드합니다.
2. Vercel에서 저장소를 Import합니다.
3. Framework Preset은 Next.js를 선택하고 Deploy합니다.

## 구현 범위
- 180문항 0~3점 응답
- 애니어그램 9유형 분포
- CCLP 4축 절대환산 및 v2.5 표시점수
- 성경인물 9유형, Top 3
- 시너지 및 주의유형
- 모바일 결과 화면과 인쇄/PDF 저장

## 확인 필요
- 원본 Excel의 문항 저작권 및 실제 서비스 이용 권한
- 개인정보 처리방침 및 동의문
- 서버 저장, 관리자 화면, 사용자 인증은 포함하지 않은 로컬 브라우저 MVP
