# CCLP 공동체 리더십 프로파일

사랑의교회 대학6부 모바일 검사. 구글 로그인 없이 180문항에 응답하고 결과를 바로 읽습니다.

## 실행과 검증

```sh
npm ci
node scripts/verify-engine.cjs
npm run build
npm run dev
```

## 원본 반영

CCLP_v2.5_Master_Engine_REPORT_SCORE.xlsx의 01_응답입력, 설정, v2.0_문항재태깅, v2.4_캐릭터관계, 07_결과지데이터, 08_출력가이드와 보고서 표시점수 수식을 반영했습니다. 기존 JSON의 공개가중치가 180개 모두 0인 오류를 수정했습니다. 역량 1, 기질 0.35, 그림자 0과 원본의 축·인물 가중치를 적용합니다.

결과는 애니어그램 프로파일, 심화해석, 공동체 프로파일, 사역 프로파일 네 구역입니다. 원본의 문항별 공개 표현 및 관계 설명은 화면에서 출처를 구분합니다. 그 밖의 상세 해설과 추천말씀은 새로 작성한 웹용 해설입니다. 통합·퇴행 연결은 측정 결과가 아닌 전통적 해석의 참고 방향입니다.

동점은 같은 순위로 표시합니다. 엑셀 MATCH가 동점에서 같은 인물을 여러 번 선택하는 문제를 피하기 위해 TOP 3는 서로 다른 인물을 원본 순서로 표시하고 동점 안내를 제공합니다. 모든 응답이 같은 경우 해석 제한을 표시합니다. 원점수와 내부 절대환산 점수는 엔진에 보존하고 화면에는 v2.5 표시점수를 사용합니다. 표시점수 보정 때문에 0점 응답은 10점으로 표시됩니다.

## 결과 보관

이름, 응답, 검사일, 무작위 결과 코드를 localStorage에 저장합니다. 생일과 전화번호 뒷자리는 검사 시작 확인 후 보관하지 않습니다. 타인의 결과를 개인 정보로 검색하는 기능이나 서버 전송은 없습니다. 같은 기기·브라우저의 결과 코드 재조회와 저장본 삭제를 지원합니다. 저장 실패해도 결과를 먼저 표시하고 인쇄/PDF로 보관할 수 있습니다. 다른 기기 조회와 관리자 통합 화면은 별도 저장·인증 개발이 필요합니다.

## 검증 범위

15개 독립 원본 수식 fixture(0~3점 경계, 교차 응답, 무작위 응답)로 4축·인물 원점수, 내부점수, 표시점수를 비교합니다. 잘못된 응답, 동점, 보정 경계와 1~2구역 언어 분리를 함께 검증합니다. fixture는 원본 수식을 Python에서 별도로 계산한 기대값이며 Excel 앱 자체 재계산 검증은 아닙니다.
